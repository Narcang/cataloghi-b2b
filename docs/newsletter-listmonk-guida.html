Data: Luglio 2026

1. Architettura: chi fa cosa

Amazon SES non è il server. PikaPods o Elestio ospitano Listmonk (applicazione + database contatti). Amazon SES consegna le email ai destinatari. Wix mostra solo il form di iscrizione.
Sito Wix (iframe) → PIKAPODS / ELESTIO (Listmonk) → AMAZON SES (IP dedicato) newsletter.dominio.it database 12k+ contatti consegna email
ComponenteCos’èCosa fa
PikaPods / Elestio Hosting gestito Listmonk Server applicazione, database contatti, pannello admin, form iscrizione, HTTPS
Amazon SES Servizio AWS di invio Recapita le newsletter — non ospita dati né applicazioni
Wix Sito web Embed iframe del form — nessun codice backend necessario

3. IP dedicato: cos’è

Ogni email parte da un indirizzo IP. Gmail e Outlook lo usano per decidere inbox vs spam.

TipoCome funzionaCosto
IP condiviso IP usato anche da altri clienti AWS Incluso (0 € extra)
IP dedicato IP usato esclusivamente da voi; reputazione solo vostra ~24 €/mese

Con invii regolari fino a 100k/mese si consiglia l’IP dedicato, accompagnato da warm-up graduale (2k → 5k → 10k → …) nelle prime settimane.

4. Integrazione Wix: è semplice?

Sì — l’integrazione Wix è la stessa per Opzione A e B, ed è semplice. Non servono automazioni Wix, webhook, codice Velo né spostare il sito da Wix. Bastano 3 passi lato Wix.

Cosa serve su Wix

  • Piano Wix con HTML embed / iframe (presente sui piani Business e superiori)
  • Accesso al DNS del dominio (separato dall’editor Wix) per il subdomain newsletter

3 passi su Wix (circa 1–2 ore)

  1. DNS: creare newsletter.cliente.it che punta a PikaPods/Elestio
  2. Pagina Wix: aggiungere elemento “HTML embed” o “iframe”
  3. Incollare il codice:
<iframe
  src="https://newsletter.cliente.it/subscription/form"
  width="100%"
  height="420"
  frameborder="0"
  style="border:0; max-width:480px;"
  title="Iscriviti alla newsletter">
</iframe>

Il visitatore compila il form dentro la pagina Wix. I dati vanno direttamente su Listmonk (PikaPods). Wix non gestisce contatti né email.

Cosa NON dovete fare su Wix

  • ❌ Installare plugin o app newsletter
  • ❌ Scrivere codice backend (Velo)
  • ❌ Configurare automazioni o webhook
  • ❌ Spostare il sito da Wix

  2. Warm-up IP dedicato: invii graduali nelle prime settimane
  3. PikaPods: pod con almeno 512 MB–1 GB RAM per 12k+ contatti
  4. DNS: SPF, DKIM, DMARC obbligatori

6. Piano operativo — Opzione B (PikaPods)

Fase 1 — Infrastruttura (3–4 ore)

  1. Account AWS + attivazione Amazon SES (regione EU)
  2. Account PikaPods → deploy Listmonk (1-click dal catalogo)
  3. Configurare dominio custom newsletter.cliente.it su PikaPods (HTTPS automatico)
  4. Listmonk → Settings → SMTP con credenziali SES + IP dedicato
  5. Credenziali admin sicure

Fase 2 — Deliverability SES (3–4 ore + attesa AWS 1–3 gg)

  1. Record SPF, DKIM, DMARC sul DNS del dominio
  2. Richiesta Production Access + quota 100k/giorno
  3. Attivazione IP dedicato su SES

Fase 3 — Listmonk + Wix (2–3 ore)

  1. Lista newsletter pubblica + double opt-in + hCaptcha
  2. Test form: https://newsletter.cliente.it/subscription/form
  3. Embed iframe su pagina Wix + test mobile

Fase 4 — Migrazione e go-live (4–5 ore)

  1. Export ~12.000 contatti da Brevo → import Listmonk
  2. Migrazione template HTML
  3. Invii test → warm-up graduale → campagne a regime

Piano operativo — Opzione A (Elestio)

Identico all’Opzione B, sostituendo il deploy PikaPods con Elestio (piano medio). Tempi e integrazione Wix restano equivalenti; costo hosting più alto.
